# Sha256 Encoder Demo

## Features

- React
- TypeScript
- Vite
- MUI
- Storybook
- React Testing Library + Vitest
- Prettier & Eslint formatting
- Devcontainer support

## Overview

This app demos a React client-side sha256 encoder that supports large files

## Quickstart

1. Run [devcontainer](https://code.visualstudio.com/docs/devcontainers/containers) via vscode (to skip setting up your environment)

2. Install packages

```bash
yarn install
```

3. Build

```bash
yarn build
```

4. Test

```bash
yarn test
```

5. Run storybook

```bash
yarn storybook
```

6. Run the app

```bash
yarn dev
```
